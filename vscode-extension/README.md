# تله‌پرامپتر برای VS Code

اتصال **داخل خود ویرایشگر** — دقیقاً جایی که کد تایپ می‌کنید. یک فایل جافایل
ساده، بدون وابستگی و بدون مرحله‌ی build.

## چه می‌کند

| ویژگی | توضیح |
|---|---|
| **متن ghost روی مکان‌نما** | خطِ بعدیِ مورد انتظار به‌صورت کدرنگ کنار مکان‌نما می‌آید (مثل Copilot) و با تایپِ درست جلو می‌رود؛ به‌محض غلط شدن پنهان می‌شود |
| **نوار وضعیت** | `62% · 45wpm` زنده در پایین پنجره |
| **اعلان اتمام** | وقتی تایپ تمام شد یا فایل با کد برابر شد |
| **دستور‌ها** | `Teleprompter: Show Window` / `Show Status` / `Reset Drill` |

هیچ‌وقت داخل فایل شما چیزی نمی‌نویسد؛ سرور محلی (`127.0.0.1:4783`) با
`fs.watchFile` پیشرفت را می‌بیند.

## نصب

```bash
./install.sh          # خودش در ~/.vscode/extensions (و cursor/windsurf) نصب می‌کند
```

بعد در VS Code: `Developer: Reload Window`

## نکته‌ها

- ghost فقط برای **فایل هدفِ تمرین فعال** نشان داده می‌شود (از `/api/state`).
- اگر ghost را ندیدید، `editor.inlineSuggest.enabled` روشن باشد.
- پورت با `TELEPROMPTER_PORT` قابل تغییر است.
